Run a read-only git command against the working tree, without a shell. `args` holds the words after `git`, one per array element — no pipes, redirects, or glob expansion. The first element must be a read-only verb: `blame`, `describe`, `diff`, `grep`, `log`, `ls-files`, `rev-parse`, `shortlog`, `show`, `status`, or a listing form of `branch`, `tag`, `remote`, or `config`. Anything that writes, reconfigures the repository, or shells out to another program (`push`, `commit`, `checkout`, `-C`, `--exec-path`, `--textconv`, and the like) is rejected before it runs.

Use this for git-history questions a static read cannot answer: who last changed a line (`blame`), what a commit touched (`show`), how a file evolved (`log --follow --`), or what changed between two revisions (`diff`).
