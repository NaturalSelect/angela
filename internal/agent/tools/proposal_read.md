Read back the branch's proposal document. Use it to see the current state of the proposal before revising it — after a run of edits, or when the earlier text is no longer in view. `ProposalEdit` refuses to edit a proposal you have not read; drafting or editing it yourself counts as having read it.

- Reads up to 200 lines from the start by default; use `offset` (0-based) and `limit` to read later sections of a longer document.
