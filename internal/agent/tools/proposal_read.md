Read back the branch's proposal document. Use it when you need to see the current state of the proposal before revising it — after a run of edits, or when the earlier text is no longer in view. Editing does not require reading first: `ProposalEdit` matches against the stored document whether or not you have it in front of you.

- Reads up to 200 lines from the start by default; use `offset` (0-based) and `limit` to read later sections of a longer document.
